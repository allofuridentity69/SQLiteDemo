# SEG2505 – Semaine 6 : SQLite (Java)

Implémentation du tutoriel Android Developers « Enregistrer des données avec SQLite ».

- `FeedReaderContract` : schéma et contrat (table `entry`, colonnes `title`, `subtitle`)
- `FeedReaderDbHelper` : sous-classe de `SQLiteOpenHelper` (création / mise à niveau)
- `MainActivity` : insertion, lecture, suppression et mise à jour, avec affichage du résultat
